Términos de uso

Fecha de vigencia: 11 de noviembre de 2026

Estos Términos de uso regulan el uso de America Revelada CX, una herramienta local de Windows para automatizar la preedición del programa América Revelada dentro de DaVinci Resolve.

1. Naturaleza de la herramienta

America Revelada CX es una herramienta privada suministrada sin garantías de ningún tipo, expresas o implícitas. Se entrega tal como está, para uso local en la computadora del usuario.

2. Revisión antes de publicar

La herramienta genera un plan de edición y posiciones en la línea de tiempo a partir de las indicaciones del documento. El usuario debe revisar el plan y la línea de tiempo antes de publicar cualquier contenido. MuViProject no se hace responsable de errores derivados de una publicación sin revisión.

3. Autorización sobre los documentos

El usuario es responsable de tener autorización para acceder a los documentos utilizados con la herramienta. La aplicación solo accede al documento que el usuario indica expresamente y no modifica, elimina ni escribe documentos o archivos de Google.

4. Acceso de solo lectura

La aplicación utiliza únicamente permisos de lectura de Google Docs y Google Drive. Todo el procesamiento se realiza localmente en la computadora del usuario y los datos no se envían a MuViProject ni a terceros. Consulte la Política de privacidad para conocer el detalle completo.

5. Sin afiliación

La herramienta no está afiliada, patrocinada ni aprobada por Google ni Blackmagic Design. DaVinci Resolve es una marca de Blackmagic Design. Google, Google Docs y Google Drive son marcas de Google LLC.

6. Contacto

Para cualquier consulta sobre estos Términos de uso, escriba a contact@muviproject.com.
