Política de privacidad

Fecha de vigencia: 11 de noviembre de 2026

Esta Política de privacidad explica qué datos utiliza America Revelada CX, una herramienta local de Windows para automatizar la preedición del programa América Revelada dentro de DaVinci Resolve, y cómo los protege.

Permisos solicitados

La aplicación solicita únicamente permisos de lectura:

  • Google Docs, solo lectura.
  • Google Drive, solo lectura.

No existe ningún permiso de escritura.

Uso efectivo de los permisos

  • La aplicación utiliza la API de Google Docs para leer el contenido, la estructura, el formato y los colores del documento indicado por el usuario.
  • Utiliza la API de Google Drive únicamente para leer los comentarios asociados con ese documento.
  • Aunque el permiso de Drive es de lectura, la aplicación no explora ni procesa otros archivos del usuario.
  • La aplicación solo accede al documento que el usuario indica expresamente.
  • La aplicación no modifica, elimina ni escribe documentos o archivos de Google.

Procesamiento y almacenamiento

  • Todo el procesamiento se realiza localmente en la computadora del usuario.
  • Las credenciales y el token OAuth se almacenan localmente en esa computadora.
  • Los datos pueden quedar incluidos en archivos JSON locales de auditoría generados por el propio usuario.
  • MuViProject no recibe ni almacena estos datos en servidores. La aplicación no tiene un servidor propio.
  • Los datos no se venden, comparten ni transfieren a terceros.
  • Los datos no se usan para publicidad, elaboración de perfiles ni entrenamiento de inteligencia artificial.
  • La aplicación no utiliza inteligencia artificial.

Control del usuario

El usuario mantiene el control total de sus datos y de la autorización:

  • Puede eliminar los archivos JSON locales generados por la aplicación.
  • Puede eliminar la autorización borrando el token local almacenado en su computadora.
  • Puede revocar el acceso en cualquier momento desde la configuración de seguridad de su cuenta de Google.

Declaración sobre las API de Google

“El uso y la transferencia de información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso limitado.”

Contacto

Para cualquier consulta sobre esta Política de privacidad, escriba a contact@muviproject.com.
